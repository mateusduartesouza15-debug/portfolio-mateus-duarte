# Portfólio Mateus Duarte

Portfólio profissional de Mateus Duarte, desenvolvedor e web designer freelancer.

O projeto inclui uma apresentação dos serviços, processo de trabalho, contato e três sites demonstrativos:

- Amana Restaurante
- Bravo Barbearia
- Linha Arquitetura

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```

Os arquivos prontos para hospedagem serão gerados na pasta `dist`.
